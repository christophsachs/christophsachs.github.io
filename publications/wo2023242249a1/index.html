Device for controlling an actuator unit and system having the device, the actuator unit and a pantograph

Inventors: Carsten Hauenschild; Christoph Sachs; Alexander Dederer

Publication number: WO2023242249A1

Authority: WIPO / PCT

Publication date: 2023-12-21

Abstract

This patent publication describes a device for controlling a fluid-operated actuator unit and a system comprising the device, the actuator unit, and a pantograph. The system relates to control, monitoring, and safe venting of actuator units in pantograph applications.
